#  JobSwap

> *Ai obosit de jobul tău? Încearcă-l pe al altuia.* 

**JobSwap** este un joc de tip *Simulation* creat în **Unity**, disponibil direct în browser pe [itch.io](https://freopa.itch.io/jobswap) care pune intrebarea: ce s-ar întâmpla dacă niște monștri ar încerca să facă joburi obișnuite de oameni?

Misiunea ta?
*  **Ține piept clienților dificili:** Oamenii pot fi greu de mulțumit, dar trebuie să îți păstrezi calmul (și deghizarea).
*  **Dă restul corect:** Calculează și oferă restul fără să dai de bănuit.
*  **Treci testul de „umanitate”:** Casa de marcat are un sistem care te testează constant — trebuie să demonstrezi că ești om și să nu fii demascat!


---

### Despre joc

*  **Gen:** Simulation
*  **Platformă:** Web / HTML5 
*  **Engine:** Unity

###  Cum se joacă?

1. Intră pe [pagina de itch.io](https://freopa.itch.io/jobswap).
2. Apasă **Run game** și așteaptă să se încarce build-ul WebGL.
3. Intră în rol, fă schimb de joburi și vezi cât de bine te descurci!

Planuri de viitor
